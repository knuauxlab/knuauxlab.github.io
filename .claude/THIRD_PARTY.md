# 외부 스킬 출처

이 폴더의 일부 파일은 오픈소스 프로젝트에서 가져왔다. 업데이트할 때는 아래 저장소에서 해당 파일만 다시 복사한다.

| 파일 | 출처 | 라이선스 |
|---|---|---|
| `agents/planner.md`, `agents/architect.md` | [affaan-m/ECC](https://github.com/affaan-m/ECC) | MIT |
| `commands/ecc-plan.md` (원본 `commands/plan.md`, Claude Code 내장 `/plan`과 겹치지 않도록 이름 변경) | affaan-m/ECC | MIT |
| `skills/search-first/`, `skills/verification-loop/` | affaan-m/ECC | MIT |
| `skills/design-taste-frontend/` | [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) | MIT |

ECC는 전체 설치(minimal 프로필 포함) 대신 필요한 파일만 골라 가져왔다. 스킬 약 50개와 다른 에디터용 설정까지 설치되기 때문이다.
